# Campus Thrift — Working Prototype

A self-contained student-to-student campus marketplace prototype.

## Run
No server or database is required for this demo.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Everything works in the browser using localStorage.

## Demo
- Browse and search listings
- Filter by category/type
- View listing details
- Express interest with a message
- Create sell/donate listings
- Create student requests
- My Listings / My Requests
- Change listing status
- Delete your own listings
- Report a listing
- Switch demo user from the top-right menu

## Prototype note
This is intentionally a simple working front-end prototype for a college demonstration. Data persists in the browser's localStorage. A production CAMPUS+ integration would replace the demo user switcher and localStorage with the central authentication/user service and shared backend/database.
